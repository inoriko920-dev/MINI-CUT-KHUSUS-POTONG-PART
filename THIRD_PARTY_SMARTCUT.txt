MiniCut Studio Agent includes an open-source SmartCut source snapshot pinned to
upstream commit 9d8dbae57d1cad3597956e10cf746d3170adf72c for frame-accurate cutting with
minimal recoding around cut points. The upstream project metadata at this commit
still reports version 1.7. This snapshot is intentionally newer than the v1.7
release tag and includes upstream fixes for final-GOP finalization and valid
frame duration handling.
